Mega Man X ReGenesis Practice Edition
A fan-made practice build for Mega Man X ReGenesis 1.00.91, created by Poisoncurls for speedrun practice and section training.
This is an unofficial community project and is not affiliated with or endorsed by the ReGenesis developers or Capcom.
Current Version
Practice Prototype 0.4.2
- Difficulty is fixed to Veteran
- Uses separate practice save data
- Includes direct stage/checkpoint launching
- Includes a visual loadout editor
- Includes keyboard and controller shortcuts
- Includes title-screen credit: “Practice Edition created by Poisoncurls”
Practice Controls
Key	Action
1–8	Load main stages
Shift+1–Shift+4	Load Fortress 1–4
Shift+5	Load GBD Bonus Stage
0	Lock/restart current practice checkpoint
-	Previous checkpoint
=	Next checkpoint
F11	Open Stage / Checkpoint menu
F12	Open Loadout menu


Controller Shortcuts
Input	Action
Select + L1	Open Stage / Checkpoint menu
Select + R1	Open Loadout menu


The controller menus support D-Pad / left-stick navigation, shoulder-button page changes, Jump to select/apply where appropriate, and Dash to cancel.
Stage / Checkpoint Menu
The practice launcher contains:
- 8 main stages
- Fortress 1–4
- GBD Bonus Stage
- Direct checkpoint selection
- Original ReGenesis stage-select boss portraits
- Sigma portrait for fortress stages
- GBD portrait for the bonus stage
Keyboard controls inside the menu:
- Up / Down: select stage
- Left / Right: select checkpoint
- Tab: change page
- Enter: launch
- F11 / Escape: cancel
Loadout Menu
The visual loadout editor lets you configure practice equipment before restarting the selected checkpoint.
It supports:
- Boss weapons
- Armor abilities
- Heart Tanks
- Sub-Tanks
- Sub-Tank fill level
- Hadouken
- Hado preset
- Base preset
The Hado loadout enables all boss weapons, armor upgrades, Heart Tanks and Sub-Tanks, fills all Sub-Tanks, and unlocks Hadouken.
Hadouken retains the normal game requirements: use the standard X-Buster and have full 32 HP.
Sub-Tank fill is represented in half-tank units from 0/8 through 8/8.

Installation / Running
1. Download the latest release ZIP.
2. Extract it to its own folder.
3. Run ReGenesis_Practice_0.4.2.exe.
The included source/debug.gd file is for future maintenance; it is not required to play.
Windows Security Notice
Because this is a modified, unsigned executable, Windows may display a security warning.
Do not disable Windows Security or antivirus protection globally.
Feedback / Bugs
This is still a prototype. If you find a broken checkpoint, menu issue, controller problem, or incorrect loadout behavior, please include:
- What stage/checkpoint you were using
- What input you pressed
- What you expected to happen
- What actually happened
That makes bugs much easier to reproduce and fix.
